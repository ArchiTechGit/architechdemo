HTL Launch Instructions

How to run the Health Transformation Lab pre-admission demo, and what happens behind the scenes when you do.

How to Run Demo
  1. 1 Open the Referral Form and submit it.
  2. 2 An SMS is received with a message asking to call for pre-enrollment.
What the Demo Does
  1. 1 The Microsoft Form takes the submission.
  2. 2 The submission is passed to Microsoft Power Automate, which posts the submission details to a Webex CC Connect Flow webhook.
  3. 3 The webhook receives the payload, takes the mobile number, and SMS's the submitter asking them to call the number.
  4. 4 In a real workflow, this is also where the payload would send the data to a medical record system for pre-admission records.
  5. 5 The patient calls the number provided in the SMS and speaks to the AI Agent.
  6. 6 The AI Agent completes a pre-admission action, capturing a set of entities in a conversational manner.
  7. 7 This data is then posted to the patient's record.
