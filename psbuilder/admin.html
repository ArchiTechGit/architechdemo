PS BUILDER — ADMIN

Enter GitHub access token

Needs a fine-grained personal access token scoped to this repo only, with Contents: Read and write permission. Stored only in this browser's local storage — never sent anywhere except GitHub's API.

How to get a token
  1. Go to github.com/settings/personal-access-tokens/new (sign in if asked).
  2. Give it any Token name, e.g. "psbuilder-admin".
  3. Under Resource owner, switch the dropdown from your personal account to ArchiTechGit (the org that owns this repo) — repo-scoping only shows up once the owner is set to the org.
  4. Under Repository access, select Only select repositories, then use Select repositories to pick ArchiTechGit/architechdemo.
  5. Under Permissions, click + Add permissions, search for Contents and check it — it's added under the Repositories tab. Set its access level to Read and write.
  6. Click Generate token (it may read "Generate token and request access" — the org may need to approve it before it works). Copy the token (starts with github_pat_) — GitHub only shows it once.
  7. Paste it below and click Continue.
